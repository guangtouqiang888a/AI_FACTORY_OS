## 1. Recommended Documentation Structure（目标目录结构建议）

设计依据：权威等级 · 读取频率 · Reality 优先 · 历史隔离 · 审计隔离。
**不**把 8+1 机械塞进单一 `core/` 目录。

```
docs/
├── entry/                 # 会话入口（最高读取频率）
│   └── CONTROL_CENTER
├── governance/            # 规则与裁决（慢变）
│   ├── AUTHORITY_MODEL
│   ├── PROJECT_CONSTITUTION
│   └── DECISION_LOG
├── state/                 # Reality 文档投影（唯一事实入口）
│   ├── CURRENT_STATE
│   └── reference/         # PROJECT_STATUS / snapshots（非权威）
├── architecture/          # 目标架构 + 模块 Status 登记
│   ├── UNIFIED_ARCHITECTURE
│   ├── MODULE_REGISTRY
│   └── reports/
├── business/              # 现行商业战略与商业域报告
│   ├── BUSINESS_STRATEGY
│   └── reports/
├── execution/             # 如何执行 / 如何更新 / 执行台账
│   ├── EXECUTION_PROTOCOL
│   ├── KNOWLEDGE_UPDATE_PROTOCOL
│   ├── CURSOR_EXECUTION_HISTORY   # 与治理规则分离
│   ├── guides/
│   └── reports/
├── blueprint/             # Design Reference（≠ Production）
│   ├── commercial/
│   ├── content_factory/
│   ├── cognition/
│   ├── database/
│   └── general/
├── history/               # 历史解释（不得覆盖 Reality）
│   └── EVOLUTION_CONTEXT + historical snapshots
├── audit/                 # 审计与验证（保持独立；已存在）
│   ├── asset/ | database/ | migration/ （可选细分）
│   └── *.md
└── archive/               # 旧历史参考（禁止删除）
    ├── BUSINESS_PLAN / WORK_PRINCIPLES（已裁决降级）
    └── unclassified/
```

| 目录 | 权威/用途 | 读取频率 | 隔离目的 |
|------|-----------|----------|----------|
| `entry/` | 会话入口 | 最高 | 先找到 Recovery |
| `governance/` | 规则/DEC | 高（启动） | 与 Blueprint 分离 |
| `state/` | Reality 投影 | 高 | Reality 优先 |
| `architecture/` | 设计+模块 Status | 中高 | Design ≠ Runtime |
| `business/` | 商业方向 | 中 | 愿景≠完成态 |
| `execution/` | 协议+台账 | 中 | History≠Core 规则 |
| `blueprint/` | 规划 | 低（按需） | Blueprint≠Production |
| `history/` | 演进解释 | 低（按需） | 历史隔离 |
| `audit/` | 验证证据 | 低 | 审计隔离 |
| `archive/` | 降级参考 | 极低 | 禁止删除 |
