# KNOWLEDGE MODEL

## 五层动态知识模型

### L0 — Project Constitution
最稳定：我们是什么、为什么存在、基本规则是什么。

### L1 — Architecture
系统结构、边界、依赖和演化原则。

### L2 — Product Knowledge
用户、问题、假设、指标、验证结果。

### L3 — Engineering Knowledge
技术标准、测试、接口、数据库、部署、安全。

### L4 — Active Work
当前 Task、计划、阻塞、实施、验证。

### L5 — Evidence
真实世界事实、测试、运行结果、用户反馈、商业结果。

## 稳定性原则
L0/L1 相对稳定；L2/L3 随系统演化；L4 高频变化；L5 是事实积累。

## 重要原则
知识不是越多越好。系统应该让 AI 快速找到需要的知识，而不是强迫 AI 记住所有知识。

Current State 是导航；Core 是稳定规则；Task 是当前工作；Evidence 是事实；History 是过去。
