# AI_FACTORY_OS

AI_FACTORY_OS 是一个以人为最终 Owner、以 AI 为工程协作者、以 GitHub 为长期事实载体、以自动化验证为安全护栏、以真实世界证据驱动持续演化的软件系统。

## 核心闭环
HUMAN OWNER → GOAL → PRODUCT → TASK → AI ENGINEERING → AUTOMATED GUARDS → REVIEW → RELEASE → REAL WORLD → EVIDENCE → LEARNING → PRODUCT

## 角色
- Human Owner：目标、方向、最终判断、风险与最终授权。
- ChatGPT：架构、推理、规划、审查、Closure Review、学习总结。
- Cursor：本地实现、工程操作、测试与技术执行。
- GitHub + Automation：代码、历史、决策、证据与机械护栏。

## 重要原则
1. Cursor PASS ≠ Task PASS。
2. 重要结论必须有可追溯证据。
3. 风险越高，授权越严格。
4. 规则优先机械执行，而不是依赖 AI 记忆。
5. 架构允许演化；变化通过 Change/Migration 管理。
6. AI Provider/Agent 必须可替换。
7. Core 保持小而稳定；动态信息进入 Work / Evidence / History。
