# AI_FACTORY_OS

## Project positioning

AI_FACTORY_OS is a human-owned software system in which AI acts as an engineering collaborator, GitHub is the long-term carrier of project facts, automated validation is intended as a safety guardrail, and real-world evidence is intended to drive continuous evolution.

## The problem it aims to solve

AI_FACTORY_OS is **not** primarily about:

- making AI write more code
- replacing programmers with AI
- collecting prompts
- arranging documentation directories for their own sake

Its real goal is:

> to become an engineering system in which AI can participate in software evolution continuously, under clear boundaries, with verification and traceable facts.
